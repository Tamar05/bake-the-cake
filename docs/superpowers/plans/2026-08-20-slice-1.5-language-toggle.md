# Slice 1.5: Language Toggle (EN / עברית) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two header buttons (`EN` / `עברית`) that switch the whole app's labels between English and Hebrew, mirror the layout right-to-left for Hebrew, and remember the choice across refreshes.

**Architecture:** Builds directly on Slice 1 (on `master`). A small pure-logic helper (`src/i18n/language.ts`) holds both dictionaries in one map and reads/saves the chosen language in the browser's `localStorage`. `App.tsx` keeps a `language` state, passes `dictionaries[language]` as the existing `t` prop (so the Slice 1 components switch for free), and sets the page's `dir`/`lang` in an effect. A presentational `LanguageToggle` renders the two buttons. Pure logic is unit-tested; components are verified by type-check and the manual browser check.

**Tech Stack:** React 18 + TypeScript + Vite 5 + Vitest 2 (unchanged from Slice 1).

## Global Constraints

- **Build on `master`.** Slice 1 is already merged in. Each task's commit lands on `master`; the user's settings prompt for approval on `git commit`, which we honor.
- **Bilingual, no hardcoded UI text:** every user-facing string comes from the `en` / `he` dictionaries. The only literals allowed are the two button faces `EN` and `עברית` (language names, shown in their own script in both modes) and the two-letter language codes `'en'` / `'he'`.
- **Test config unchanged:** Vitest runs `src/**/*.test.ts` in the `node` environment. `localStorage` does not exist in that environment, so tests that touch it must stub it (as pocket-pt stubs globals with `vi.stubGlobal`).
- **English and Hebrew dictionaries must keep identical keys** — guarded by the existing `src/i18n/i18n.test.ts`. Any key added to one must be added to the other.
- **Components are verified by `npm run build` (type-check), not unit tests** — do not add test files for `.tsx` components.
- **Scope:** only the app's own labels switch. Do NOT translate typed-in content, add a server/database, add accounts, or support languages beyond English and Hebrew.

- [ ] **Step 3: Write the minimal implementation** `src/i18n/language.ts`

```ts
import type { Dictionary } from './types';
import { en } from './en';
import { he } from './he';

// The two languages the app supports.
export type Language = 'en' | 'he';

// Both dictionaries in one place, looked up by language code.
export const dictionaries: Record<Language, Dictionary> = { en, he };

// Where the chosen language is stored in the browser's small-settings store.
const STORAGE_KEY = 'btc-language';

// Reads the saved language, defaulting to English if nothing valid is stored.
export function loadLanguage(): Language {
  const saved = localStorage.getItem(STORAGE_KEY);
  return saved === 'he' || saved === 'en' ? saved : 'en';
}

// Saves the chosen language so it survives a refresh.
export function saveLanguage(language: Language): void {
  localStorage.setItem(STORAGE_KEY, language);
}
```

```tsx
import type { Language } from '../i18n/language';
import type { Dictionary } from '../i18n/types';

type Props = {
  t: Dictionary;
  language: Language;
  onChange: (language: Language) => void;
};

// Button faces stay the literal language names (shown in their own script
// regardless of the active language), so they are not dictionary strings.
const OPTIONS: { code: Language; label: string }[] = [
  { code: 'en', label: 'EN' },
  { code: 'he', label: 'עברית' },
];

export default function LanguageToggle({ t, language, onChange }: Props) {
  return (
    <div className="language-toggle" role="group" aria-label={t.languageLabel}>
      {OPTIONS.map((option) => (
        <button
          key={option.code}
          type="button"
          className={option.code === language ? 'active' : ''}
          aria-pressed={option.code === language}
          onClick={() => onChange(option.code)}
        >
          {option.label}
        </button>
      ))}
    </div>
  );
}
```

### Task 3: Wire the toggle into App + right-to-left flip + styling

Connect the toggle to App's `language` state (which drives the whole app's text and the page direction), and style the buttons. Deliverable: the full Slice 1.5 experience working in the browser.

**Files:**
- Modify (replace): `src/App.tsx`
- Modify (append): `src/styles/base.css`

**Interfaces:**
- Consumes: `dictionaries`, `loadLanguage`, `saveLanguage`, `Language` from `src/i18n/language.ts`; `LanguageToggle`; the existing `RequestForm`, `RequestList`, `createRequest`, `CakeRequest`, `RequestDraft`.
- Produces: the assembled Slice 1.5 screen. Language state starts from `loadLanguage()`; changing it saves the choice and updates `document.documentElement.dir` / `.lang`.

- [ ] **Step 1: Replace `src/App.tsx`**

```tsx
import { useState, useEffect } from 'react';
import RequestForm from './components/RequestForm';
import RequestList from './components/RequestList';
import LanguageToggle from './components/LanguageToggle';
import { dictionaries, loadLanguage, saveLanguage, type Language } from './i18n/language';
import { createRequest } from './lib/requests';
import type { CakeRequest, RequestDraft } from './types';

export default function App() {
  // Start from whatever language was saved last (English the first time).
  const [language, setLanguage] = useState<Language>(loadLanguage);
  const [requests, setRequests] = useState<CakeRequest[]>([]);

  const t = dictionaries[language];

  // Keep the page's reading direction and lang attribute in step with the language.
  useEffect(() => {
    document.documentElement.lang = language;
    document.documentElement.dir = language === 'he' ? 'rtl' : 'ltr';
  }, [language]);

  function handleLanguageChange(next: Language) {
    setLanguage(next);
    saveLanguage(next);
  }

  function handleAdd(draft: RequestDraft) {
    const request = createRequest(draft);
    setRequests((prev) => [request, ...prev]); // newest first
  }

  return (
    <main className="app">
      <header className="app-header">
        <LanguageToggle t={t} language={language} onChange={handleLanguageChange} />
        <h1>{t.appTitle}</h1>
        <p>{t.tagline}</p>
      </header>
      <RequestForm t={t} onAdd={handleAdd} />
      <RequestList t={t} requests={requests} />
    </main>
  );
}
```
