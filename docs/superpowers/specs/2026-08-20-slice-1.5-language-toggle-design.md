# Slice 1.5 — Language Toggle (EN / עברית) — Design

*Written 2026-08-20. Small slice building directly on `master`, on top of Slice 1.*

---

## 1. Goal

A small language switch in the header flips the whole app between **English** and
**Hebrew**. Choosing Hebrew mirrors the layout to **right-to-left**. The chosen
language is **remembered** across refreshes, and the switch is always available to
change back.

Only the app's own words (labels, buttons, messages) switch — these already live
in the `en` / `he` word-lists from Slice 1. The **content people type** is NOT
translated here; that is the later "Translate" button (a Slice 7 magic touch that
depends on the Slice 2 server).

## 2. What the user sees

- Two small buttons in the page header: **`EN`** and **`עברית`**. The active
  language is highlighted.
- Clicking a button switches every label/button/message on the page instantly.
- When **עברית** is active, the whole page reads right-to-left: the header
  buttons, the form fields, and the request cards all flow from the right.
- Refreshing the page (or closing and reopening it) keeps the last chosen
  language. The buttons still let you switch back any time.

*(Note: refreshing still clears the cake-request list — that is unchanged from
Slice 1 and is Slice 2's job to fix. Only the language choice is remembered.)*

## 3. How it works (plain English)

- A small helper keeps both word-lists together as a map `{ en, he }` and knows
  how to **save** the chosen language into the browser's small-settings store
  (`localStorage`) and **read** it back, defaulting to English the first time.
- `App.tsx` holds a `language` setting (starts from whatever was saved). The `t`
  ("translations") it passes to the form and list is simply `dictionaries[language]`
  — so everything already reading from `t` switches for free.
- Switching language does three things: updates that setting, saves it to the
  browser, and sets the page's **direction** (`dir="rtl"` + `lang="he"` for
  Hebrew; `dir="ltr"` + `lang="en"` for English) on the top-level page element.
- A new `LanguageToggle` component renders the two buttons and reports which one
  was clicked.

## 4. Design principles applied

- **Smallest thing that works:** reuses the existing `t`-based components untouched
  — the switch just changes *which* word-list `t` points to.
- **Keep looks and logic separate:** the save/read-language logic is a plain,
  testable `.ts` helper; the buttons are a presentational component; the page-
  direction flip is a one-line effect.
- **Foundation for later:** the language state introduced here is exactly what the
  future "Translate" button will reuse to know the target language.

## 5. Components / files

- **New** `src/i18n/language.ts` — `Language` type (`'en' | 'he'`), the
  `dictionaries` map `{ en, he }`, and `loadLanguage()` / `saveLanguage(lang)`.
- **New** `src/i18n/language.test.ts` — proves save→load round-trips and that the
  default is English (using a stubbed `localStorage`, matching the node test env).
- **New** `src/components/LanguageToggle.tsx` — the two `EN` / `עברית` buttons.
- **Modify** `src/App.tsx` — hold `language` state, apply the direction flip,
  render the toggle, pass `dictionaries[language]` as `t`.
- **Modify** `src/styles/base.css` — style the toggle buttons (active vs inactive)
  and confirm the layout looks right in right-to-left.
- **Modify** `src/i18n/en.ts` / `src/i18n/he.ts` / `src/i18n/types.ts` — add one
  accessible label for the toggle group (e.g. "Language" / "שפה") so the switch
  itself is not a hardcoded string. The button faces stay the literal language
  names `EN` and `עברית` (conventionally shown in their own script either way).

## 6. What this slice deliberately does NOT do

- Translate typed-in content (that is the later AI-powered Translate button).
- Add any server, database, or accounts.
- Support languages beyond English and Hebrew.

## 7. How we'll know it works

- Automated: the new save/read-language test passes, and the existing
  "English and Hebrew have identical keys" test keeps guarding the word-lists.
- By hand in the browser: click **עברית** → whole app switches to Hebrew and
  mirrors right-to-left; refresh → still Hebrew; click **EN** → back to English,
  left-to-right.
